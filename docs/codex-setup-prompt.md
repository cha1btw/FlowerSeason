# Сообщение для Codex на новом компьютере

Перед этим: Docker Desktop установлен и открыт, Даниил вошёл в свой GitHub и
Vercel на этом компьютере. Скопируйте текст между линиями в Codex целиком.

---

Привет! Это мой сайт Flower Season, я веду его сама. Я не программист: объясняй
просто и спрашивай меня перед тем, как что-то удалить, закоммитить или
опубликовать. Токены и пароли в этот чат я не вставляю, не проси их.

1. Найди проект на компьютере: папку, где `git remote -v` указывает на
   github.com/cha1btw/FlowerSeason. Если такой нет, склонируй в
   `~/Projects/FlowerSeason`. Сделай `git pull`.
2. Прочитай `AGENTS.md` и `docs/handover.md` и всегда соблюдай правила оттуда.
3. Проверь, что всё подключено: git, Docker (`docker info`), Node 22+, вход в
   GitHub (`gh auth status`, аккаунт `cha1btw`) и доступ к репозиторию. Чего нет,
   скажи, что установить или кого попросить войти.
4. Запусти сайт: `docker compose up -d --build`. Проверь http://localhost:3000,
   `/business`, `/workshops`, потом `docker compose exec app npm run typecheck`
   и `docker compose exec app npm test`.
5. Проведи меня по шагам раздела 2.3 в `docs/handover.md`: запуск заявок в
   Telegram на живом сайте (мой бот, мой Telegram ID, база данных и переменные в
   Vercel, webhook). В Telegram и Vercel всё делаю я сама, ты говоришь, куда
   нажать, и после каждого шага проверяешь результат.
6. Ничего не коммить. В конце дай памятку на 5 строк: как запустить сайт, как
   опубликовать правку, как откатить сайт, если он сломался.
